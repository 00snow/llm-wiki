# 反向傳播（Backpropagation）

> **一句話**：反向傳播是一種「倒著算回去」的方法，用連鎖律一次算出損失對**每一個參數**的斜率，讓[[optimization|梯度下降]]知道每個參數該往哪邊調、調多少。

## 用生活比喻來想

一家餐廳的菜被客人嫌太鹹（損失很大）。主廚要找出是誰的問題：

1. 主廚先問**最後擺盤的人**：「你加了多少醬？」
2. 擺盤的人說：「醬是**醬料師**給我的。」主廚再去問醬料師。
3. 醬料師說：「鹽是**備料員**準備的。」再往回問……

責任從「結果」**一站一站往回傳**，每一站只要回答「我的輸出受上一站影響多少」，最後就能知道每個人該負多少責任。

- 菜太鹹 = 損失
- 每個工作站 = 網路裡的一個小運算
- 「該負多少責任」= **梯度**

## 它是怎麼運作的

### 為什麼需要它？

[[optimization]] 告訴我們：`新參數 = 舊參數 − 學習率 × 斜率`。
問題是，[[neural-network|神經網路]]可能有幾百萬個參數，每個都要算斜率。一個一個算太慢了，反向傳播能**一次把全部算完**。

### 兩個方向

| 階段 | 方向 | 在做什麼 |
|------|------|---------|
| **正向傳播（Forward）** | 輸入 → 輸出 | 照平常的方式算出預測和損失，並把中間結果**存起來** |
| **反向傳播（Backward）** | 輸出 → 輸入 | 從損失開始，倒著把梯度一站一站傳回去 |

### 核心工具：連鎖律（Chain Rule）

如果 f 是由 q 算出來的，q 又是由 x 算出來的：

```
df/dx = (df/dq) × (dq/dx)
```

- **df/dx**：x 動一點點，f 會變多少（這就是我們要的梯度）
- **df/dq**：q 動一點點，f 會變多少（「後面傳來的」梯度）
- **dq/dx**：x 動一點點，q 會變多少（這一站自己的「局部梯度」）

白話來說：**往回傳的梯度 = 後面傳來的梯度 × 自己的局部梯度**。

### 三種運算的「傳話規則」

| 運算 | 梯度怎麼往回傳 | 比喻 |
|------|-------------|------|
| 加法 `x + y` | 後面傳來多少，就**原封不動**分給每個輸入 | 平分責任 |
| 乘法 `x × y` | 給 x 的梯度 = 後面的梯度 × **y 的值**（反之亦然） | 交叉換位 |
| 取最大值 `max(x, y)` | 梯度**全部**給比較大的那個，另一個得 0 | 只找主嫌 |

## 動手算一次

算式：`f = (x + y) × z`，輸入 x = −2、y = 5、z = −4。

先把它拆成兩站：

```
q = x + y        （加法站）
f = q × z        （乘法站）
```

### 第 1 步：正向傳播，把值算出來

```
q = −2 + 5 = 3
f = 3 × (−4) = −12
```

### 第 2 步：反向傳播，把梯度傳回去

從終點開始：f 對自己的梯度是 1。

**乘法站** `f = q × z`（交叉換位）：

```
df/dz = q = 3
df/dq = z = −4
```

**加法站** `q = x + y`（原封不動分出去）：後面傳來的梯度是 −4

```
df/dx = −4 × 1 = −4
df/dy = −4 × 1 = −4
```

### 結果

| 變數 | 值 | 梯度 | 意思 |
|------|----|------|------|
| x | −2 | **−4** | x 增加一點點，f 會**減少** 4 倍那麼多 |
| y | 5 | **−4** | y 增加一點點，f 也會減少 4 倍 |
| z | −4 | **3** | z 增加一點點，f 會**增加** 3 倍 |

假設 f 是損失、我們想讓它變小：梯度是負的就把變數調大（x、y），梯度是正的就把變數調小（z）。這正是梯度下降 `新值 = 舊值 − 學習率 × 梯度` 在做的事。

## 常見誤會

- ❌ 反向傳播就是梯度下降 → ✅ 反向傳播只負責**算斜率**；用斜率去**更新參數**的是梯度下降。兩者搭配使用。
- ❌ 反向傳播是資料倒著流過網路 → ✅ 倒著流的是**梯度**，不是資料。資料只在正向傳播時流過。
- ❌ 每個參數的梯度要分開重算一遍 → ✅ 反向傳播走一趟就能算出全部，因為中間結果都共用。
- ❌ 輸入的大小不重要 → ✅ 輸入放大 1000 倍，權重的梯度也會放大 1000 倍，學習率可能要跟著調低。

## 重點回顧

- 反向傳播 = 用連鎖律，從損失開始倒著算出每個參數的梯度。
- 先正向（算值、存起來），再反向（傳梯度）。
- 往回傳的梯度 = 後面傳來的梯度 × 自己的局部梯度。
- 加法平分、乘法交叉、取最大值只給大的。
- 它負責「算斜率」，[[optimization|梯度下降]]負責「用斜率更新」。
