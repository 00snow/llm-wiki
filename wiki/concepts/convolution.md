# 什麼是卷積（Convolution）

> **一句話**：卷積就是拿一個小小的「窗口」在資料上滑過去，每到一個位置就把窗口裡的數字「乘一乘、加起來」，得到一個新的數字。

## 用生活比喻來想

想像你拿著一個**放大鏡**，在一張照片上由左到右、由上到下慢慢移動。每移到一個位置，你就根據放大鏡裡看到的東西，在筆記本上寫下一個分數，例如「這裡有沒有邊緣？」

- 放大鏡 = **卷積核（kernel）／濾波器（filter）**
- 慢慢移動 = **滑動**
- 寫下的分數 = **輸出**

整張照片掃完，筆記本上就是一張新的「特徵圖」。

## 它是怎麼運作的

### 四個步驟

數學上，卷積可以拆成：

1. **翻轉**：把窗口（g）左右翻過來
2. **平移**：把它移到某個位置
3. **相乘**：窗口和資料對應位置的數字一一相乘
4. **加總**：把乘積全部加起來，就是這個位置的輸出

每個位置都做一次，就得到整條（或整張）結果。

### 公式

離散版本（電腦用的）：

```
(f * g)[n] = Σ f[m] × g[n − m]
```

- **f**：原始資料（例如一串聲音訊號、一張圖片）
- **g**：窗口／卷積核
- **n**：現在算到第幾個位置
- **m**：窗口裡的每一格
- **Σ**：全部加起來
- `g[n − m]` 裡的「減 m」就是「翻轉」的意思

### 一個小提醒

在[[cnn|卷積神經網路]]裡，實際上大多**沒有做「翻轉」**這一步，嚴格來說叫「互相關（cross-correlation）」。但大家還是習慣叫它卷積。因為卷積核本來就是學出來的，翻不翻轉對結果沒有影響。

### 卷積用在哪裡？

| 領域 | 用途 |
|------|------|
| 影像處理 | 模糊、銳化、找邊緣 |
| AI | [[cnn]] 的核心運算 |
| 訊號處理 | 濾掉雜訊 |
| 統計 | 加權移動平均 |
| 聲學 | 模擬回聲 |
| 代數 | 多項式乘法 |

## 動手算一次

### 一維：移動平均

資料 f = [3, 6, 9, 6, 3]，窗口 g = [⅓, ⅓, ⅓]（取三格平均；左右對稱，所以翻不翻轉都一樣）：

```
位置 1：(3 + 6 + 9) / 3 = 6
位置 2：(6 + 9 + 6) / 3 = 7
位置 3：(9 + 6 + 3) / 3 = 6
```

結果是 [6, 7, 6]——原本尖尖的資料被「抹平」了。這就是**模糊**的原理。

### 二維：找出邊緣

一張 5×5 的灰階小圖（0 = 黑、9 = 白），左邊黑、右邊白：

```
0 0 9 9 9
0 0 9 9 9
0 0 9 9 9
0 0 9 9 9
0 0 9 9 9
```

一個 3×3 的「找垂直邊緣」卷積核：

```
−1  0  1
−1  0  1
−1  0  1
```

放在左上角（第 1～3 欄）：每一列是 `−1×0 + 0×0 + 1×9 = 9`，三列加起來 = **27**。
往右移一格（第 2～4 欄）：每一列是 `−1×0 + 0×9 + 1×9 = 9`，加起來 = **27**。
再往右一格（第 3～5 欄）：每一列是 `−1×9 + 0×9 + 1×9 = 0`，加起來 = **0**。

每一列都一樣，所以輸出是：

```
27 27 0
27 27 0
27 27 0
```

窗口跨在黑白交界上時數值很大（27），整片都是白色時是 0。**卷積核成功找到了邊緣！**

## 常見誤會

- ❌ 卷積是很高深的數學 → ✅ 實際做的事就是「滑動、相乘、加總」。
- ❌ 卷積只能用在圖片 → ✅ 聲音、訊號、統計都會用到。
- ❌ 卷積核要人自己設計 → ✅ 傳統影像處理是人設計；在 CNN 裡，卷積核的數字是**訓練學出來的**。

## 重點回顧

- 卷積 = 拿一個小窗口在資料上滑動，每個位置做「乘一乘、加起來」。
- 不同的窗口能做出不同效果：模糊、找邊緣……
- CNN 裡用的其實是不翻轉的版本，但一樣叫卷積。
