# 損失函數（Loss Function）

> **一句話**：損失函數是用來算「模型的預測錯了多少」的公式；訓練模型的目標，就是讓這個數字越小越好。

## 用生活比喻來想

射飛鏢時，你怎麼知道自己進步了？看**飛鏢離紅心有多遠**。

- 離紅心越遠 → 損失越大
- 正中紅心 → 損失是 0

損失函數就是那把「量距離的尺」。沒有它，模型根本不知道自己是在進步還是退步。

## 它是怎麼運作的

### 基本想法

對每一筆資料：

```
誤差 = 正確答案 − 模型的預測
```

誤差可能是正的也可能是負的，直接加起來會互相抵消，所以要先讓它「都變成正的」。有兩種常見做法：

| 名稱 | 做法 | 平均之後叫 |
|------|------|-----------|
| **L1 損失** | 取**絕對值**：\|誤差\| | **MAE**（平均絕對誤差） |
| **L2 損失** | 取**平方**：誤差² | **MSE**（均方誤差） |

另外還有 **RMSE = √MSE**，開根號之後單位就和答案一樣，比較好解讀。

### 平方帶來的效果

平方會讓**大的誤差變得更大**，而小於 1 的誤差反而變小：

| 誤差 | 絕對值（L1） | 平方（L2） |
|------|------------|-----------|
| 0.5 | 0.5 | 0.25 |
| 1 | 1 | 1 |
| 3 | 3 | **9** |

所以：

- **MSE** 會很在意「錯很大」的點，容易被**離群值**拉著走。想要重罰大錯誤時用它。
- **MAE** 對每個誤差一視同仁，比較不受離群值影響。不想讓少數怪資料主導時用它。

### 分類問題呢？

上面講的是「預測一個數字」（例如房價、油耗）。如果是「預測類別」（例如貓還是狗），通常會用另一種叫**交叉熵（Cross-Entropy）**的損失（待查證：之後收錄來源再補完整說明）。

## 動手算一次

### 例 1：一筆資料的 L2 損失

一個預測汽車油耗的模型：`預測 = 34 + (−4.6) × 車重`

車重 2.37（千磅）：

```
預測 = 34 + (−4.6 × 2.37) = 34 − 10.9 = 23.1
實際 = 24
L2 損失 = (24 − 23.1)² = 0.9² = 0.81
```

### 例 2：MAE 和 MSE 比一比

3 筆資料：

| | 第 1 筆 | 第 2 筆 | 第 3 筆 |
|--|------|------|------|
| 正確答案 | 3 | 5 | 7 |
| 預測 | 2 | 5 | 9 |
| 誤差 | 1 | 0 | −2 |

```
MAE = (|1| + |0| + |−2|) / 3 = 3 / 3 = 1
MSE = (1² + 0² + (−2)²) / 3 = 5 / 3 ≈ 1.67
```

MSE 比 MAE 大，是因為第 3 筆的誤差 2 被平方成 4。

![同樣三筆誤差，取絕對值和取平方的差別](diagrams/loss.svg)

### 例 3：哪個模型比較好？

10 筆資料：

- 模型 A：4 個點各差 1 → MSE = (1+1+1+1) / 10 = **0.4**
- 模型 B：2 個點各差 2 → MSE = (4+4) / 10 = **0.8**

兩個模型的「總誤差距離」都是 4，但用 MSE 來看，B 比較差，因為平方放大了比較大的誤差。

## 常見誤會

- ❌ 損失越接近 0 越好，最好剛好是 0 → ✅ 損失 = 0 常代表模型把訓練資料「背」起來了（過度擬合），遇到新資料反而表現差。
- ❌ MSE 一定比 MAE 好 → ✅ 要看情況：在意大錯誤用 MSE，資料有很多怪值用 MAE。
- ❌ 損失函數就是準確率 → ✅ 損失是給模型「訓練時」看的，準確率是給人看的成績單。

## 重點回顧

- 損失 = 預測和正確答案之間的距離。
- 訓練目標：讓損失最小。
- L1 / MAE 取絕對值；L2 / MSE 取平方，會放大大誤差。
- 有了損失，下一步才能談怎麼「降低」它。
