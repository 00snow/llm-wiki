# 神經網路（Neural Network, NN）

> **一句話**：神經網路是由很多個「小計算單元」一層一層連起來的模型，每個單元做「加權加總 → 加偏差 → 過一個非線性函數」，整個網路就能學出很複雜的規律。

## 用生活比喻來想

想像一間公司在決定「要不要錄取一個應徵者」：

1. **第一層員工（輸入層）**：只負責把資料交上來——學歷、經驗年數、面試分數。
2. **中間主管（隱藏層）**：每位主管看重的東西不同。A 主管很在意經驗，B 主管很在意面試。他們各自打一個分數。
3. **老闆（輸出層）**：綜合每位主管的意見，做出最後決定。

「每位主管有多在意某件事」就是**權重**。一開始大家都亂給，之後根據「錄取的人表現好不好」慢慢調整——這就是**訓練**。

## 它是怎麼運作的

### 三種層

```
 輸入層        隱藏層          輸出層
  x₁ ──┐    ┌─ 神經元 ─┐
  x₂ ──┼────┼─ 神經元 ─┼────  y′
  x₃ ──┘    └─ 神經元 ─┘
```

| 層 | 作用 |
|----|------|
| 輸入層（Input layer） | 放進原始資料，例如 x₁、x₂、x₃ |
| 隱藏層（Hidden layer） | 中間的計算層，裡面的節點叫**神經元**；可以有很多層 |
| 輸出層（Output layer） | 給出最後答案 y′ |

### 一個神經元在做什麼

```
輸出 = σ( w₁·x₁ + w₂·x₂ + … + b )
```

- **x**：上一層傳來的數值
- **w（權重, weight）**：這個輸入有多重要
- **b（偏差, bias）**：一個額外加上的數，讓神經元可以整體往上或往下調
- **σ（激勵函數, activation function）**：把結果再轉換一次（下面會解釋為什麼一定要有）

權重和偏差合稱**參數（parameters）**，訓練就是在找出最好的參數。

### 為什麼一定要有激勵函數？

如果每個神經元只做「加權加總」，那不管疊幾層，整個網路**還是一條直線**的關係——線性計算再做線性計算，結果仍然是線性的。就像不管你把幾把直尺接起來，都畫不出一個圓。

激勵函數加入「彎曲」，疊很多層之後才能學到複雜的形狀。常見的三種：

| 名稱 | 公式 | 輸出範圍 | 特色 |
|------|------|---------|------|
| Sigmoid | 1 / (1 + e⁻ˣ) | 0 ～ 1 | S 形曲線，像一個「機率」 |
| Tanh | tanh(x) | −1 ～ 1 | 也是 S 形，但更陡 |
| **ReLU** | max(0, x) | 0 ～ ∞ | 負數變 0、正數不變；計算簡單，比較不會「梯度消失」，**建議先用它** |

## 動手算一次

### 算一個神經元

輸入 x = (2, 3)，權重 w = (0.5, −1)，偏差 b = 1，激勵函數用 ReLU：

```
第 1 步 加權加總：0.5 × 2 + (−1) × 3 = 1 − 3 = −2
第 2 步 加偏差：  −2 + 1 = −1
第 3 步 過 ReLU： max(0, −1) = 0
```

這個神經元的輸出是 **0**——它對這筆資料「沒有反應」。

### 數一數有幾個參數

3 個輸入、1 個輸出：

- **沒有隱藏層**（就是線性模型）：3 個權重 + 1 個偏差 = **4 個參數**
- **加一層 4 個神經元的隱藏層**：
  - 隱藏層：每個神經元有 3 個權重 + 1 個偏差 = 4，共 4 個神經元 → 4 × 4 = 16
  - 輸出層：接收 4 個神經元 → 4 個權重 + 1 個偏差 = 5
  - 合計 **21 個參數**

加了一層，參數就變成 5 倍多。真正的大模型有數十億個參數，就是這樣一層層疊出來的。

## 常見誤會

- ❌ 神經網路跟人腦一樣 → ✅ 只是「受到啟發」，實際上就是一堆乘法、加法和簡單函數。
- ❌ 層數越多一定越好 → ✅ 層數多可以學更複雜的東西，但也更難訓練、需要更多資料。
- ❌ 疊很多層就能學到複雜規律 → ✅ 沒有激勵函數的話，疊再多層也只是一條直線。

## 重點回顧

- 神經網路 = 輸入層 → 隱藏層 → 輸出層。
- 一個神經元：加權加總 → 加偏差 → 激勵函數。
- 權重和偏差是「參數」，訓練就是找最好的參數。
- 激勵函數提供非線性；預設先用 ReLU。
