# 提示工程（Prompt Engineering）

> 透過設計輸入給 LLM 的文字（prompt），讓它更穩定地產出想要結果的技巧。

## 重點
- 把**角色、任務、限制、輸出格式**寫清楚。
- **Few-shot**：先給幾個輸入輸出範例，模型會模仿。
- **Chain of Thought**：請模型「一步一步想」，推理題常更準確。
- 給模型「不知道就說不知道」的出口，能減少 [[hallucination]]。
- 需要最新或私人資料時，prompt 技巧不夠，要搭配 [[rag]]。

## 說明
LLM 會根據輸入預測最合理的接續（見 [[large-language-model]]），
所以 prompt 越具體，「合理接續」的範圍就越小、越接近你要的。

一個好用的 prompt 結構：

| 部分 | 範例 |
|------|------|
| 角色 | 你是一位高中物理老師 |
| 任務 | 用三句話解釋什麼是慣性 |
| 限制 | 不要用公式，舉一個生活例子 |
| 格式 | 用條列式輸出 |

## 例子

```
請把下列句子分類為「正面」或「負面」。

句子：這家店的拉麵超好吃 → 正面
句子：等了一個小時還沒上菜 → 負面
句子：店員很親切，下次還會再來 →
```

模型看到前兩個範例（few-shot），就會照同樣格式回答「正面」。
