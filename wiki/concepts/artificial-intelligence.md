# 什麼是 AI（Artificial Intelligence）

> **一句話**：AI 就是讓電腦去做「以前只有人類的智慧才做得到」的事，例如學習、推理、看懂圖片、聽懂語言。

## 用生活比喻來想

想像你在教一個新來的實習生分辨「好吃的芒果」。

- **舊方法**：你寫一本規則手冊——「顏色偏黃、按下去微軟、聞起來香」。這就像早期的 AI，人把規則一條條寫進電腦。
- **新方法**：你直接拿一千顆芒果給他摸、給他吃，讓他自己歸納出規則。這就是現在主流的**機器學習**：不寫規則，而是給大量例子讓電腦自己學。

## 它是怎麼運作的

### AI 是一個很大的傘

AI 不是單一技術，而是一整個領域。它主要包含這幾塊：

| 能力 | 在做什麼 | 例子 |
|------|---------|------|
| 學習 | 從資料中找規律（機器學習、深度學習、強化學習） | 推薦你可能喜歡的影片 |
| 推理與決策 | 根據知識做判斷 | 下棋時選下一步 |
| 感知 | 看懂圖片、聽懂聲音（電腦視覺） | 手機的人臉解鎖 |
| 自然語言處理 | 理解和產生人類語言 | 翻譯、聊天機器人 |
| 生成 | 創造新的內容（生成式 AI） | 畫圖、寫文章 |

### 一層包一層的關係

```
人工智慧 AI
 └─ 機器學習：讓電腦從資料學習，而不是人寫規則
     └─ 深度學習：用「很多層」的神經網路來學習
         └─ 大型語言模型（LLM）、影像辨識模型……
```

這個 wiki 接下來要講的 [[neural-network]]、[[cnn]]，都屬於「深度學習」這一層。

### 簡短的歷史

| 年份 | 發生了什麼 |
|------|-----------|
| 1943 | 麥卡洛克與皮茨設計出「類神經元」模型——神經網路的起點 |
| 1950 | 圖靈提出「圖靈測試」：機器能不能讓人分不出它是機器？ |
| 1956 | 達特茅斯會議，「人工智慧」正式成為一個研究領域 |
| 1974 | 研究經費被砍，進入第一次「AI 寒冬」 |
| 1980 年代 | 專家系統（把專家規則寫進電腦）讓 AI 再度熱門 |
| 1987 起 | 熱潮退去，AI 再次受挫 |
| 1990 | 楊立昆證明卷積神經網路能辨識手寫數字（見 [[cnn]]） |
| 2012 起 | 深度學習開始主導整個領域 |
| 2016 | AlphaGo 打敗圍棋世界冠軍李世乭 |
| 2017 | Transformer 架構出現 |
| 2020 | OpenAI 推出 GPT-3 |

可以發現 AI 經歷過好幾次「爆紅 → 失望 → 再爆紅」。

### 強 AI 和弱 AI

- **弱 AI**：機器只是「看起來」很聰明，其實沒有真正的理解或意識。**我們現在用的所有 AI 都屬於這種。**
- **強 AI**：真的會思考、有自我意識的機器。目前還只是理論上的討論。

## 動手試一次

下面哪些是「機器學習」，哪些只是「人寫好的規則」？

| 系統 | 答案 |
|------|------|
| 計算機按 `1 + 1` 得到 `2` | 規則（人寫好的公式，不需要學） |
| 信箱自動把廣告信丟進垃圾郵件 | 機器學習（從大量被標記的信件學會判斷） |
| 紅綠燈每 60 秒切換一次 | 規則 |
| 手機相簿自動找出「所有有狗的照片」 | 機器學習（從大量圖片學會辨認狗） |

判斷的訣竅：**它的行為是人一條一條寫出來的，還是從資料中學出來的？**

## 常見誤會

- ❌ AI 就是會聊天的機器人 → ✅ 聊天機器人只是 AI 的其中一種應用，人臉辨識、推薦系統也都是 AI。
- ❌ AI 已經有意識了 → ✅ 目前所有 AI 都是「弱 AI」，沒有真正的理解或自我意識。
- ❌ AI 是最近才出現的 → ✅ 這個領域從 1956 年就開始了，只是 2012 年後深度學習讓它突飛猛進。

## 重點回顧

- AI = 讓電腦做需要人類智慧的事。
- 現代 AI 的主流是**機器學習**：給例子，讓電腦自己學出規則。
- 深度學習是機器學習的一種，用的是多層的[[neural-network|神經網路]]。
- 現在所有 AI 都是弱 AI。
