# 卷積神經網路（Convolutional Neural Network, CNN）

> **一句話**：CNN 是專門處理圖片的[[neural-network|神經網路]]，它用[[convolution|卷積]]一小塊一小塊地看圖片，而且這些「小窗口」的數字是電腦自己學出來的。

## 用生活比喻來想

你怎麼認出一隻貓？大概不是一次看整張圖，而是：

1. 先注意到一些**線條和邊緣**
2. 線條組合成**耳朵、眼睛、鬍鬚**
3. 這些部位組合起來 → **是貓！**

CNN 也是這樣，一層一層從「小特徵」組合成「大概念」。前面幾層找邊緣，後面幾層找形狀，最後判斷是什麼東西。

## 它是怎麼運作的

### 為什麼不用一般的神經網路就好？

因為圖片太大了。一張 200×200 的彩色圖片（3 個顏色通道），如果用一般的全連接神經網路：

```
一個神經元就需要 200 × 200 × 3 = 120,000 個權重
```

而一層通常有很多個神經元，參數多到難以訓練，也很容易過度擬合。

### CNN 的兩個聰明招數

| 招數 | 意思 | 好處 |
|------|------|------|
| **局部連接** | 每個神經元只看一小塊區域（感受野） | 不用看整張圖 |
| **參數共享** | 同一個卷積核滑過整張圖，用同一組權重 | 參數大幅減少 |

參數共享的效果有多大？以 AlexNet 第一層（96 個 11×11×3 的卷積核）為例：

- 共享參數：**34,944** 個
- 不共享：**105,705,600** 個

差了大約 3,000 倍！

### CNN 由四種層組成

| 層 | 做什麼 | 有參數嗎 |
|----|-------|---------|
| **CONV（卷積層）** | 用卷積核在圖上滑動找特徵 | 有，是學出來的 |
| **ReLU** | 把負數變成 0（激勵函數） | 沒有 |
| **POOL（池化層）** | 把圖縮小，只留重要資訊 | 沒有 |
| **FC（全連接層）** | 放在最後，輸出「每個類別的分數」 | 有 |

一個很小的例子：

```
輸入 32×32×3
 → CONV（12 個卷積核）→ 32×32×12
 → ReLU               → 32×32×12
 → POOL               → 16×16×12
 → FC                 → 10 個類別的分數
```

常見的架構公式：

```
輸入 → [ [CONV → ReLU] × N → POOL ] × M → [FC → ReLU] × K → FC
```

（N 通常不超過 3，K 通常小於 3）

> 小提醒：CNN 裡的「卷積」大多沒有做翻轉，嚴格來說是「互相關（cross-correlation）」。但因為卷積核是學出來的，翻不翻轉對結果沒有影響（見 [[convolution]]）。

### 卷積層的三個設定

- **F（卷積核大小）**：窗口多大，例如 3×3
- **S（步幅, stride）**：每次移動幾格
- **P（填充, padding）**：在圖片邊緣補幾圈 0

輸出大小公式：

```
輸出寬度 = (輸入寬度 − F + 2P) / S + 1
```

- 常見設定 F = 3、S = 1、P = 1，輸出大小**和輸入一樣**
- 算出來必須是整數，不是整數代表設定不合法

### 最大池化（Max Pooling）

最常見的是 2×2、步幅 2：每個 2×2 方格**只留最大的數字**。

```
1 3 | 2 1
5 6 | 1 0        6 | 2
----+----   →   ---+---
2 0 | 3 4        2 | 8
1 1 | 8 2
```

寬高都減半，丟掉 75% 的數值，但留下最明顯的特徵。

## 動手算一次

### 算輸出大小

7×7 的輸入，用 3×3 的卷積核（F = 3），不補邊（P = 0）：

```
步幅 S = 1：(7 − 3 + 0) / 1 + 1 = 5   → 輸出 5×5
步幅 S = 2：(7 − 3 + 0) / 2 + 1 = 3   → 輸出 3×3
```

不合法的例子：輸入 10、F = 3、P = 0、S = 2：

```
(10 − 3 + 0) / 2 + 1 = 4.5   → 不是整數，卷積核沒辦法剛好滑完 ❌
```

### 數參數

一個 5×5 的卷積核，作用在 32×32×3 的圖上：

```
權重 = 5 × 5 × 3 = 75，再加 1 個偏差 = 76 個參數
```

不管圖片多大，這個卷積核都只有 76 個參數——這就是參數共享的威力。

## 常見誤會

- ❌ CNN 一次看整張圖 → ✅ 它一次只看一小塊，再一層層組合起來。
- ❌ 卷積核是工程師設計的 → ✅ 卷積核的數字是透過[[optimization|梯度下降]]學出來的。
- ❌ 一定要自己從頭訓練 CNN → ✅ 實務上通常拿別人訓練好的模型（例如在 ImageNet 上訓練的）再微調。課程的建議是："don't be a hero."
- ❌ 卷積核越大越好 → ✅ 疊三層 3×3 的參數（27C²）比一層 7×7（49C²）少，效果通常更好。

## 重點回顧

- CNN = 專門處理圖片的神經網路。
- 靠**局部連接**和**參數共享**大幅減少參數。
- 四種層：CONV、ReLU、POOL、FC。
- 輸出大小 = (W − F + 2P) / S + 1。
- 歷史上，1990 年楊立昆就證明了 CNN 能辨識手寫數字。
