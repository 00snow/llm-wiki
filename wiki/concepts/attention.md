# 注意力機制（Attention）

> 讓每個 token 計算「我該多注意其他哪些 token」，再依權重整合它們資訊的方法。

## 重點
- **自注意力（self-attention）**：同一段文字中的 token 彼此互相注意。
- 每個 token 會產生三個向量：**Query、Key、Value**。
- Query 和 Key 的相似度決定注意力權重，再用權重加總 Value。
- **多頭注意力（multi-head）**：同時跑好幾組注意力，各自捕捉不同關係。
- 運算量隨序列長度平方成長，這是 context window 有上限的原因之一。

## 說明
可以把它想成在圖書館找資料：
- **Query**：我想找什麼（目前這個 token 的需求）
- **Key**：每本書的標籤（其他 token 能提供什麼）
- **Value**：書的內容（真正被拿走的資訊）

計算方式（概念版）：

```
權重 = softmax( Query · Key / √維度 )
輸出 = Σ 權重 × Value
```

多頭注意力就像同時派好幾個人去找：有人專看文法、有人專看代名詞指的是誰。

## 例子
「小明把蘋果給了小華，因為**他**餓了。」
處理「他」時，注意力會給「小華」很高的權重（因為「餓了」所以拿到蘋果的人比較合理），
模型因此理解「他」指的是小華。
