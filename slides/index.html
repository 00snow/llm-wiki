02 神經網路

動手算：一個神經元

輸入 x = (2, 3)，權重 w = (0.5, −1)，偏差 b = 1

  1. 加權加總0.5 × 2 + (−1) × 3 = −2
  2. 加偏差−2 + 1 = −1
  3. 過 ReLUmax(0, −1) = 0

輸出 0：這個神經元對這筆資料「沒有反應」。

來源 神經網路07 / 28
講者備註偏差是額外加上的一個數，讓神經元整體往上或往下調。激勵函數 ReLU 是 max(0, x)：負數變 0、正數不變。權重和偏差合稱參數。

02 神經網路

為什麼一定要有激勵函數？

只做加權加總，疊幾層都還是一條直線。

  • 就像把幾把直尺接起來，也畫不出一個圓
  • 激勵函數加入「彎曲」，疊多層才學得到複雜形狀
  • 常見：Sigmoid（0～1）、Tanh（−1～1）、ReLU
  • 建議先用 ReLU：負數變 0、正數不變，計算簡單
來源 神經網路08 / 28
講者備註ReLU 還有一個好處是比較不會「梯度消失」，等講完梯度再回來看。

03 損失函數

動手算：MAE 和 MSE

三筆資料的誤差是 1、0、−2

  1. MAE（取絕對值）= (1 + 0 + 2) / 3 = 1
  2. MSE（取平方）= (1 + 0 + 4) / 3 ≈ 1.67
  3. 差在哪誤差 2 被平方成 4

MSE 很在意「錯很大」的點；MAE 比較不受離群值影響。

來源 損失函數10 / 28
講者備註正確答案 3、5、7，預測 2、5、9。誤差有正有負，直接加會抵消，所以先取絕對值或平方。

04 梯度下降

動手算：學習率 0.1 vs 1.1

L(w) = (w − 3)²，斜率 2(w − 3)，從 w = 0 出發

  1. 公式新 w = 舊 w − 學習率 × 斜率
  2. 學習率 0.10 − 0.1 × (−6) = 0.6
  3. 再一步0.6 − 0.1 × (−4.8) = 1.08
  4. 學習率 1.10 − 1.1 × (−6) = 6.6
  5. 再一步6.6 − 1.1 × 7.2 = −1.32

0.1 越走越靠近 3；1.1 在 3 的兩邊越跳越遠。

來源 最佳化與梯度下降12 / 28
講者備註學習率太小要走很多步，太大會跳過谷底甚至越來越大。

05 反向傳播

動手算：f = (x + y) × z

x = −2、y = 5、z = −4

  1. 正向q = −2 + 5 = 3，f = 3 × (−4) = −12
  2. 乘法站交叉換位df/dz = q = 3，df/dq = z = −4
  3. 加法站原封不動df/dx = df/dy = −4

梯度負的把變數調大（x、y），正的調小（z），損失就會變小。

來源 反向傳播15 / 28
講者備註連鎖律：往回傳的梯度 = 後面傳來的梯度 × 自己的局部梯度。

05 反向傳播

三種運算的傳話規則

運算梯度怎麼往回傳比喻
加法 x + y原封不動分給每個輸入平分責任
乘法 x × y給 x 的 = 後面的 × y 的值交叉換位
max(x, y)全部給比較大的那個只找主嫌
來源 反向傳播16 / 28
講者備註反向傳播只負責算斜率，用斜率去更新參數的是梯度下降，兩者搭配使用。

06 卷積

動手算：找出邊緣

5×5 小圖左黑（0）右白（9），3×3 卷積核每列是 −1、0、1

  1. 放左上角，每列−1×0 + 0×0 + 1×9 = 9
  2. 三列加起來 = 27
  3. 往右一格−1×0 + 0×9 + 1×9 = 9，合計 27
  4. 再往右−1×9 + 0×9 + 1×9 = 0

跨在黑白交界上是 27，整片白色是 0：找到邊緣了！

來源 什麼是卷積18 / 28
講者備註輸出是每一列都一樣的 27 27 0。

07 CNN

為什麼需要 CNN？

圖片太大了，一般神經網路的參數多到難以訓練。

  • 200×200 彩色圖：一個神經元就要 120,000 個權重
  • 局部連接：每個神經元只看一小塊
  • 參數共享：同一個卷積核滑過整張圖
  • AlexNet 第一層：共享 34,944，不共享 105,705,600
來源 卷積神經網路19 / 28
講者備註差了大約 3,000 倍。卷積核的數字是透過梯度下降學出來的。

07 CNN

CNN 的四種層

層做什麼有參數嗎
CONV 卷積層用卷積核找特徵有，學出來的
ReLU把負數變成 0沒有
POOL 池化層把圖縮小，留重要資訊沒有
FC 全連接層輸出每個類別的分數有
來源 卷積神經網路20 / 28
講者備註例如 32×32×3 的輸入，經過 12 個卷積核變 32×32×12，池化後變 16×16×12，最後 FC 輸出 10 個類別的分數。

07 CNN

最大池化：只留最大的

2×2、步幅 2：每個 2×2 方格只留最大的數字。

  • 寬高都減半
  • 丟掉 75% 的數值
  • 但留下最明顯的特徵
  • 池化層沒有參數，不用學
來源 卷積神經網路21 / 28
講者備註同一個顏色的 2×2 方格只留最大值。步幅是每次移動幾格。

07 CNN

卷積層的輸出有多大？

F = 卷積核大小、S = 步幅、P = 填充（邊緣補幾圈 0）

  1. 公式(輸入寬度 − F + 2P) / S + 1
  2. 7×7 輸入、F 是 3、P 是 0
  3. S = 1(7 − 3 + 0) / 1 + 1 = 5
  4. S = 2(7 − 3 + 0) / 2 + 1 = 3
  5. 輸入 10、S = 2(10 − 3 + 0) / 2 + 1 = 4.5

算出來不是整數（4.5），代表卷積核沒辦法剛好滑完。

來源 卷積神經網路22 / 28
講者備註常見設定 F = 3、S = 1、P = 1，輸出大小和輸入一樣。

常見誤會

✕ 學習率越大學越快
✓ 太大會跳過谷底，反而學不起來
✕ 反向傳播就是梯度下降
✓ 一個算斜率，一個用斜率更新
✕ 卷積核是工程師設計的
✓ 在 CNN 裡是訓練學出來的
✕ 損失剛好是 0 最好

這份簡報是怎麼做出來的

  • 每個錯誤都寫明要退回哪個節點
  • 只重寫錯的那幾張，最多 3 輪
  • 數字要追得回 Wiki，Wiki 再追回 raw
