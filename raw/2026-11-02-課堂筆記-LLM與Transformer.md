# 課堂筆記 2026-11-02：LLM 是怎麼運作的

（隨手筆記，之後請 AI 整理進 wiki）

- LLM 本質：給一段文字，預測「下一個 token」，一直重複 → 生出整段回答
- token 不等於字！英文常常是半個單字，中文大約 1 個字 1~2 個 token
  - 老師示範：同一句話中文比英文花更多 token → 比較貴
- 模型看到的是 token 的編號 → 轉成向量（embedding）
- 現在幾乎都用 Transformer 架構（2017 那篇 Attention Is All You Need）
  - 核心是 self-attention：每個 token 去「看」其他所有 token，決定誰比較重要
  - 例子：「小明把蘋果給了小華，因為他餓了」→ 「他」要注意到「小華」
  - multi-head：好幾組注意力同時看不同關係（文法、指代…）
  - 可以平行運算 → 比 RNN 好訓練、可以做很大
- 訓練三階段（老師畫的圖）：
  1. 預訓練：讀超大量文字，學預測下一個 token
  2. 微調 / 指令微調：學會照指令回答
  3. RLHF：人類偏好回饋，讓回答更有幫助、更安全
- context window = 模型一次能看的 token 數量上限，超過就看不到
- temperature：越高越隨機、越有創意；越低越穩定
- 問題：會一本正經地胡說八道（hallucination），因為它只是在預測「看起來合理」的字
