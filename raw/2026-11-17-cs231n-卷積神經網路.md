## 重點摘錄
- 為什麼影像要用 CNN：全連接層參數太多。200×200×3 的圖片，一個神經元就要 200×200×3 = 120,000 個權重。
- CNN 把神經元排成 3D（寬、高、深），並限制連接範圍，大幅減少參數。
- 層的種類：
  - CONV（卷積層）：可學習的濾波器（filter），在局部區域算內積
  - RELU：逐元素 max(0, x)，不改變大小
  - POOL（池化層）：固定的降採樣，沒有參數
  - FC（全連接層）：輸出各類別分數
- 範例：INPUT [32×32×3] → CONV（12 個濾波器）[32×32×12] → RELU → POOL [16×16×12] → FC [1×1×10]
- 濾波器在寬高方向滑動，每個位置算一次內積，得到一張 2D 激活圖（activation map）；有幾個濾波器就疊幾張。
- 局部連接：每個神經元只看一小塊區域（感受野），但看完整深度。例：5×5 濾波器在 32×32×3 輸入上有 5×5×3 = 75 個權重 + 1 個偏差。
- 參數共享：同一張激活圖共用一組權重。AlexNet 第一層（96 個 11×11×3 濾波器）共享後 34,944 個參數；不共享要 105,705,600 個。
- 步幅 S：濾波器每次移動幾格。零填充 P：在邊緣補 0 以控制輸出大小。
- 輸出大小：W₂ = (W₁ − F + 2P) / S + 1
  - 7×7 輸入、F=3、S=1、P=0 → 5×5；S=2 → 3×3
  - S=1 時 P=(F−1)/2 可維持大小；常見設定 F=3、S=1、P=1
  - 結果必須是整數，例如 W=10、F=3、P=0、S=2 得 4.5，不合法
- 最大池化 2×2、S=2：寬高減半、深度不變，丟掉 75% 的數值（每個 2×2 只留最大值）。
- 常見架構：INPUT → [[CONV → RELU]×N → POOL?]×M → [FC → RELU]×K → FC（通常 N ≤ 3、K < 3）
- 疊小濾波器較好：三層 3×3 共 27C² 參數，一層 7×7 要 49C²。
- 實務建議：直接用在 ImageNet 上表現好的預訓練模型再微調（"don't be a hero"）。
