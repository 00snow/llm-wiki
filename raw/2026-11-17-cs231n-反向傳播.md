## 重點摘錄
- 反向傳播（backpropagation）：反覆套用連鎖律（chain rule）來計算一個式子的梯度。
- 連鎖律：梯度用「相乘」串起來，例如 df/dx = (df/dq) × (dq/dx)。
- 在神經網路裡，f 是損失 L，輸入是訓練資料和權重；實際上是對參數（W、b）算梯度，再拿去更新參數。
- 導數的意義：整個式子對某個變數有多敏感（那個變數改一點點，輸出會變多少）。
  - 例：f(x, y) = x·y，x = 4、y = −3 → f = −12；df/dx = −3（x 增加 h，f 減少 3h）；df/dy = 4。
- 範例 f(x, y, z) = (x + y)·z：
  - 拆成 q = x + y、f = q·z
  - 輸入 x = −2、y = 5、z = −4
  - 正向：q = 3、f = −12
  - 局部梯度：df/dq = z = −4、df/dz = q = 3、dq/dx = 1、dq/dy = 1
  - 反向：dz = 3、dq = −4、dx = −4 × 1 = −4、dy = −4 × 1 = −4
- 每個運算（gate）只需要知道自己的輸出和「局部梯度」；反向時把從後面傳來的梯度乘上局部梯度，再往前傳。
- 三種運算的直覺：
  - 加法：把後面傳來的梯度「原封不動」分給所有輸入
  - 取最大值：梯度全部給比較大的那個輸入，另一個得到 0
  - 乘法：給每個輸入的梯度 = 後面傳來的梯度 × 「另一個輸入的值」
- 輸入的大小會影響權重的梯度：輸入放大 1000 倍，權重梯度也放大 1000 倍，學習率可能要調低。
- Sigmoid 的導數：dσ/dx = (1 − σ(x))·σ(x)。例：輸出 0.73 → 局部梯度 (1 − 0.73) × 0.73 ≈ 0.2。
- 實務技巧：把正向計算拆成簡單的中間變數，再倒著算回去；正向的值要先存起來給反向用；一個變數流向多條路時，梯度要相加（+=）。
